# Contributing

Bug reports and sanitized fixtures from independently hosted WinBIAP sites are
welcome. Include the public WebOPAC URL, the displayed WebOPAC version, the
integration version, and privacy-safe diagnostics.

Before opening a pull request:

1. Keep all account operations read-only.
2. Add or update a synthetic fixture and parser test.
3. Run Ruff and pytest as documented in the README.
4. Never commit credentials, cookies, real card numbers, or personal account
   content.

By contributing code, you agree that it is your own work and can be distributed
under the repository's MIT license.
